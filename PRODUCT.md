# Product

## Register

product

## Users

Advanced DeFi users who have some blockchain experience and understand basic concepts like APY/APR/Spread/Supply/Borrow. They use this tool for:

- Daily monitoring of Aave V3 multi-chain markets
- Comparing lending and borrowing rates across chains
- Tracking incentive rewards from Merit/Merkl/Brevis programs
- Simulating rate changes and portfolio effects
- Making cross-chain investment decisions

These users are typically active in DeFi protocols, understand risk management, and need precise, real-time data to make informed decisions about where to allocate their capital across different blockchain networks.

## Product Purpose

Aave APY is a React dashboard that provides comprehensive market data analysis for Aave V3 across multiple blockchain networks. The product exists to:

- Aggregate and normalize Aave V3 market data across all supported chains (Ethereum, Arbitrum, Optimism, Base, Polygon, Avalanche, etc.)
- Enable easy comparison of supply/borrow APYs to identify optimal yield opportunities
- Track additional yield sources from incentive programs (Merit, Merkl, Brevis)
- Provide forecasting tools for estimating potential returns
- Serve as a decision-support tool for DeFi users managing multi-chain portfolios

Success is measured by user adoption, reduced time to make informed yield decisions, and improved capital efficiency for DeFi users.

## Brand Personality

**Warm, Precise, Trustworthy**

- **Warm**: Approachable interface that feels like a professional financial advisor - data-driven but not cold or intimidating
- **Precise**: Exact, accurate data presentation with professional attention to detail
- **Trustworthy**: Reliable, consistent, and transparent - users must feel confident in the data quality

The interface should feel like consulting with an expert financial advisor who uses data to guide decisions, but presents information in a caring, accessible way.

## Anti-references

- **Avoid cold, clinical fintech interfaces** like traditional banking dashboards with sterile blue/gray color schemes
- **Don't emulate crypto-bro aesthetic** with neon colors, excessive animations, or gambling-like visual cues
- **Avoid generic DeFi UI patterns** that prioritize flashy yields over data clarity and risk awareness
- **Don't mimic trading platform intensity** with red/green price action visuals that could encourage impulsive decisions
- **Avoid overly complex financial platform layouts** that overwhelm users with too much information at once

## Design Principles

1. **Warm Precision** - Present precise, analytical data with a warm, approachable interface. Every number should be accurate, but the delivery should feel human and caring.

2. **Progressive Disclosure** - Show core data immediately (APYs, rates), with detailed breakdowns (incentive calculations, simulations) available on demand. Don't overwhelm users with all data at once.

3. **Multi-chain Clarity** - Make it effortless to compare opportunities across chains while maintaining clear visual separation between different networks and their unique risk profiles.

4. **Risk-Conscious Design** - Surface risk information (utilization rates, caps, liquidity depth) with appropriate visual hierarchy. Help users make informed decisions, not just chase highest yields.

5. **Data Density with Breathing Room** - Pack significant information into compact views while maintaining readability through strategic whitespace and clear typographic hierarchy.

## Accessibility & Inclusion

- **WCAG 2.1 AA compliance** for all interactive elements and data displays
- **Reduced motion support** for all animations and transitions
- **High contrast mode compatibility** ensuring data remains readable
- **Color blindness considerations** using semantic color pairs that work for common types (deuteranopia, protanopia)
- **Screen reader optimization** for data tables with proper ARIA labels and table structure
- **Keyboard navigation** support for all filtering, sorting, and portfolio management features
- **Mobile-first responsive design** ensuring touch targets meet 44px minimum on all devices

The application serves a global DeFi userbase with varying accessibility needs, device capabilities, and network conditions. Design decisions must never compromise data accessibility for visual aesthetics.
