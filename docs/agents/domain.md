# Domain Docs

This repo uses a **single-context** layout.

## Layout

- `CONTEXT.md` — Project domain language and concepts (root)
- `docs/adr/` — Architectural Decision Records (root)

## Consumer rules

- Skills read `CONTEXT.md` to understand domain terminology.
- Skills read `docs/adr/*.md` for past architectural decisions.
- When improving architecture, update `CONTEXT.md` and create new ADRs as needed.
