# Triage Labels

The triage skill uses these five canonical labels (Linear labels on the Aaveapy team):

| Label             | Meaning                                  |
|-------------------|------------------------------------------|
| `needs-triage`    | Maintainer needs to evaluate             |
| `needs-info`      | Waiting on reporter for more information |
| `ready-for-agent` | Fully specified, an AFK agent can pick up |
| `ready-for-human` | Needs human implementation               |
| `wontfix`         | Will not be actioned                     |

These labels must be created manually in the Linear project settings.
