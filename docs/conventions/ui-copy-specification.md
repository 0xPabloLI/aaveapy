# UI Copy Specification

All user-visible text strings must be documented here before implementation.
When changing copy, find the entry below and update the template + examples.
Other docs should **reference** this file rather than duplicating copy.

## 1. Protocol Cap Warning

**Entry point:** `formatProtocolCapText()` in `src/lib/portfolioCapWarnings.ts`

**Consumers:**
- `SimulationSubRow.tsx` (Reserve Table)
- `PortfolioTokenRow.tsx` → `formatCapWarningLabel()` (Portfolio)

### Templates

| Condition | Template | Example |
|---|---|---|
| User input exceeds cap | `{Supply|Borrow} limited to {X} available` | `Supply limited to $11,500 available` |
| Chain position already exceeds cap | `Current {Supply|Borrow} limited to {X} available` | `Current Borrow limited to $4,700 available` |
| Borrow limited by liquidity | `{Supply|Borrow} limited to {X} available (liquidity)` | `Borrow limited to $4,700 available (liquidity)` |
| Both current + liquidity | `Current {Supply|Borrow} limited to {X} available (liquidity)` | `Current Borrow limited to $4,700 available (liquidity)` |

### Parameters

| Parameter | Type | Effect |
|---|---|---|
| `side` | `'supply' \| 'borrow'` | Chooses "Supply" or "Borrow" label |
| `availableFormatted` | `string` | Pre-formatted available amount. Reserve Table passes `formatScenarioSize(...)` (USD/Token mode); Portfolio passes `formatUsd(...)` (pure USD) |
| `currentExceeded` | `boolean?` | Adds "Current " prefix — chain position already exceeds cap (not caused by user input) |
| `limitedByLiquidity` | `boolean?` | Appends " (liquidity)" — borrow cap constrained by available liquidity |

### Data sources

| Scenario | Data source | Notes |
|---|---|---|
| Reserve Table: user input exceeds cap | `simulation.marketMetrics.supplyCapExceeded` / `borrowCapExceeded` | `hasInput && capExceeded` branch |
| Reserve Table: chain position exceeds cap | `supplyCapBaseExceeded` / `borrowCapBaseExceeded` (computed in SimulationSubRow) | `hasInput && !capExceeded && baseExceeded` → `currentExceeded: true` |
| Portfolio: user input exceeds cap | `extractCapWarnings()` → `ProtocolCapWarning` | No `currentExceeded` in Portfolio |

## 2. Incentive Position Cap Note

**Generated by:** `buildBrevisPositionCapEffect()` / `buildMeritPositionCapEffect()` in `src/lib/incentiveCaps.ts`

**Rendered by:** Direct display of `capNote` string (no format function). Both Reserve Table (`SimulationCampaignDetail.capNote`) and Portfolio (`IncentiveCapWarning.capNote`) render the same string.

### Templates

| Source | Condition | Template | Example |
|---|---|---|---|
| Brevis | Solo cap | `Incentive on first {X}` | `Incentive on first $1,000.00` |
| Brevis | Shared supply+borrow | `Incentive on first {X} · supply + borrow` | `Incentive on first $5,000.00 · supply + borrow` |
| Brevis | + budget remaining | `Incentive on first {X} · ~{N}d earn` | `Incentive on first $1,000.00 · ~50d earn` |
| Brevis | + campaign ending | `Incentive on first {X} · ~{N}d to end` | `Incentive on first $1,000.00 · ~60d to end` |
| Merit | Self-cap | `Incentive on first {X}` | `Incentive on first $2,000.00` |

### Brevis vs Merit builder differences

Both are `kind: 'position_cap'` with the same core template. Structural differences:

| Aspect | Merit | Brevis |
|---|---|---|
| Scope / Window | `per_user` / `round_cycle` | `per_user` / `campaign_lifetime` |
| Shared supply+borrow | Not supported | Supported (appends `· supply + borrow`) |
| Duration note | Not supported | `~Nd earn` (budget) or `~Nd to end` (calendar) |
| Warning logic | `inputUsd > positionCapUsd` | `isCapBinding` (passed in) |

### Other incentive cap notes (non-position)

| Builder | Kind | Template | Example |
|---|---|---|---|
| `buildBrevisCalendarEndOnlyEffect` | informational | `~{N}d to end` | `~30d to end` |
| `buildMerklFixPoolBudgetEffect` | pool_budget | `~{N}d earn` | `~7d earn` |
| `buildMerklAprCapEffect` | apr_cap | `APR capped for low TVL` | `APR capped for low TVL` |

### Net eligibility note

| Builder | Template | Example |
|---|---|---|
| `buildNetEligibilityNote` | `Net eligible {net} of {gross}` | `Net eligible $500 of $1,000` |
| `buildCrossReserveNetEligibilityNote` | `Net eligible {net} of {gross} ({side} minus {symbols} {offsets})` | `Net eligible $500 of $1,000 (supply minus USDC+DAI borrows)` |
