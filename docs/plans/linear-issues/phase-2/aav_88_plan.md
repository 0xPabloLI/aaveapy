# AAV-88 跨链钱要包含退出路径和时间的显示 - 开发方案

## 1. Issue 概述
为跨链资金流动功能增加退出路径（Exit Path）和退出时间（Exit Time）的显示，提升用户对跨链资金状态的可视化理解。具体需求是前端展示跨链资金的退出路径信息及预计退出时间，后端提供对应数据支持。

## 2. 当前状态
- **状态**：未开始
- 代码库中暂无跨链退出路径和时间的相关数据字段及展示逻辑。
- 跨链功能相关的基础数据接口和展示尚未完善。

## 3. 影响范围
- **前端**：aaveapy 仓库 lovable 分支
  - 需要新增跨链资金退出路径和时间的UI组件或在现有组件中扩展展示
- **后端**：aave-protocol-analysis 仓库 railway 分支
  - 需要在数据聚合层和API层增加退出路径和时间字段支持

## 4. 实现方案

### 4.1 后端实现

#### 4.1.1 数据采集与聚合
- **修改文件**：
  - `src/index.ts`（根数据聚合入口）
  - 相关跨链API集成文件（如 `src/v4-fetcher.ts` 或新增跨链数据源接口）
- **逻辑变更**：
  - 增加对跨链退出路径和退出时间数据的采集逻辑，可能需要调用链上合约或第三方跨链服务API获取
  - 定义并扩展 `RuntimeReserveData` 类型，新增字段 `exitPath`（字符串或数组，描述退出路径）和 `exitTime`（时间戳或时间区间）

#### 4.1.2 API 层支持
- **修改文件**：
  - `backend/src/services/marketsApiSerialize.ts` - 序列化新增字段
  - `backend/src/controllers/marketsController.ts` - 确保API响应包含新字段
  - `backend/src/routes/markets.ts` - 路由确认支持
- **逻辑变更**：
  - 将新增字段包含在 `/api/markets` 响应中，保持字段命名与后端一致

### 4.2 前端实现

#### 4.2.1 数据类型定义
- **修改文件**：
  - `src/types/aave.ts` - 扩展市场数据类型，新增 `exitPath` 和 `exitTime` 字段

#### 4.2.2 UI 展示
- **修改文件**：
  - `src/components/dashboard/ReservesTable/` 或相关跨链展示组件
  - 可能新增 `CrossChainExitInfo.tsx` 组件，用于专门展示退出路径和时间
- **逻辑变更**：
  - 在跨链资金相关的表格或卡片中显示退出路径（如链路步骤、目标链等）和预计退出时间（格式化显示）
  - 支持字段为空或未知时的友好提示
  - 兼容响应式设计，确保移动端展示良好

#### 4.2.3 数据获取
- **修改文件**：
  - `src/hooks/useAaveMarkets.ts` - 确保从API获取并传递新增字段

### 4.3 测试
- 编写后端单元测试，验证数据采集和序列化正确
- 编写前端单元测试和集成测试，验证UI正确渲染退出路径和时间
- 手动测试跨链资金数据展示，确认信息准确且无性能问题

## 5. 依赖关系
- 依赖跨链数据源的接口稳定性和可用性
- 可能依赖 AAV-89/AAV-85 等跨链相关功能的基础设施完善
- 需与后端团队协调数据字段设计和接口变更

## 6. 验收标准
- 后端 `/api/markets` 接口返回数据包含 `exitPath` 和 `exitTime` 字段，数据格式合理
- 前端跨链资金相关视图正确显示退出路径和退出时间信息
- UI 在不同设备和屏幕尺寸下均正常显示
- 相关单元测试和集成测试通过
- 代码符合项目代码规范，且无明显性能回退

## 7. 复杂度评估
- **复杂度**：Medium
- **理由**：
  - 需要后端新增跨链退出路径和时间数据采集，可能涉及链上数据解析或第三方API调用
  - 前端需设计合理的UI展示方案，兼顾不同设备
  - 跨链数据本身复杂，数据准确性和实时性需保证，存在一定实现难度
