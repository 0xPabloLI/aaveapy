# 开发方案：AAV-89 要包含不同链的安全性显示

## 1. Issue 概述
为 AaveAPY 项目增加多链安全性显示功能。即在前端展示不同链（如 Ethereum、Polygon、Arbitrum 等）对应的安全性指标或状态，帮助用户了解各链的安全风险或保障水平。

## 2. 当前状态
未开始。代码库中暂无多链安全性相关数据采集、存储或展示的实现。

## 3. 影响范围
- 后端：aave-protocol-analysis/railway
- 前端：aaveapy/lovable

## 4. 实现方案

### 4.1 后端实现

#### 4.1.1 数据获取与存储
- **目标**：采集不同链的安全性相关数据（如链状态、风险评级、已知安全事件、合约审计结果摘要等）。
- **步骤**：
  1. 调研可用的安全性数据源（如官方安全公告、链上风险指标、第三方安全评级API）。
  2. 在 `src/` 新增 `chainSecurityService.ts`，负责调用安全性数据源接口，定时拉取并解析数据。
  3. 在数据库新增表 `chain_security`（或类似命名），字段包括：chainId、chainName、安全等级、安全事件摘要、更新时间等。
  4. 在 `persistenceService.ts` 增加对应的存储与查询接口。
  5. 在 `updateScheduler.ts` 添加定时任务，定期更新安全性数据。
  6. 在 `backend/src/services/marketsApiSerialize.ts` 或新建序列化模块，将安全性数据合并进 `/api/meta/side-data` 或新建 `/api/meta/chain-security` 接口。

#### 4.1.2 API 设计
- 新增接口 `GET /api/meta/chain-security`，返回所有支持链的安全性信息。
- 保持字段命名与前端一致，方便直接消费。

### 4.2 前端实现

#### 4.2.1 数据请求
- 在 `src/hooks/` 新增 `useChainSecurity.ts`，调用后端 `/api/meta/chain-security` 接口，缓存并提供安全性数据。

#### 4.2.2 UI 展示
- 在 `src/components/dashboard/` 新增或修改现有多链相关组件（如 `ChainPage.tsx` 或 Dashboard Header），增加安全性显示区域。
- 显示内容包括：链名称、图标、当前安全等级（用颜色或图标标识），简要安全事件说明，点击可查看详细信息（弹窗或跳转）。
- 使用 TailwindCSS 设计清晰直观的安全性标签或卡片。

#### 4.2.3 交互与体验
- 支持链列表页或仪表盘页显示对应链安全状态。
- 支持用户根据安全等级筛选或排序链。

## 5. 依赖关系
- 依赖后端安全数据接口完成。
- 可能依赖第三方安全数据源的稳定性和授权。
- 需与多链支持相关功能（如 AAV-89 相关链展示）协同开发。

## 6. 验收标准
- 后端能定时拉取并存储多链安全性数据，接口返回数据准确完整。
- 前端能正确调用接口并展示安全性信息，UI符合设计规范。
- 用户能直观识别不同链的安全等级及安全事件。
- 代码通过单元测试和集成测试，部署后无明显性能或稳定性问题。

## 7. 复杂度评估
**Medium**

理由：
- 需要设计新的数据采集与存储流程，涉及后端数据库和定时任务。
- 需调研并集成外部安全数据源，存在一定不确定性。
- 前端需新增数据请求和 UI 设计，涉及多链页面改造。
- 但整体功能边界清晰，技术难度适中。
