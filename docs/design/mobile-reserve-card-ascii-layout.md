# MobileReserveCard 排版示意（ASCII）

## 改动对比

### 1. Simulation Toggle（展开按钮）

**改动前（横向）:**
```
┌─────────────────────────────────────┐
│  Spread  +8.43%              ⌄      │  ← 文字和图标左右排列
└─────────────────────────────────────┘
       ↑ Spread 占左边
                         ↑ 图标在右边
```

**改动后（纵向）:**
```
┌─────────────────────────────────────┐
│                ⌄                    │  ← 图标在上（更紧凑）
│          Spread  +8.43%             │  ← 文字在下
└─────────────────────────────────────┘
                ↑ 上下堆叠省宽度
```

---

### 2. Batch Toggle（批量模式开关）

**改动前（横向）:**
```
┌──────────┐
│ Batch [3] │ ← 文字和数字左右并排
│    ⚪⚪   │ ← Switch 在下方（mobile 已垂直）
└──────────┘
```

**改动后（纵向 - 仅在 Portfolio 模式）:**
```
┌──────────┐
│   Batch   │  ← 标签单独一行
│    [3]    │  ← position count 在其下方
│   ⚪⚪    │  ← Switch
└──────────┘
```

### Batch Toggle 详细对比

**改动前 - 非 Portfolio 模式（mobile）:**
```
┌────────────────┐
│  Batch         │
│  ⚪⚪          │  ← 已经是上下（Switch 在下）
└────────────────┘
```

**改动前 - Portfolio 模式:**
```
┌────────────────┐
│  Batch [3] ⚪⚪ │  ← Batch 和 [3] 横向
└────────────────┘
```

**改动后 - Portfolio 模式:**
```
┌────────────────┐
│     Batch      │  ← Batch 单独一行
│      [3]       │  ← position count 在下
│     ⚪⚪       │  ← Switch 在最下
└────────────────┘
```

## 图例

- `(G)` = Token 图标
- `↗` = ExternalLink 图标
- `○` = Cap 圆环（可选显示）
- `[3]` = Position count badge
- `[9.71%]` = 激励 pill（圆角绿底）
- `⌄` = ListCollapse 图标（展开/折叠）
- `⚪⚪` = iOS-style Switch toggle
