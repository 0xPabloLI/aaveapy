## 建议布局（Proposed）

```
┌─────────────────────────────────────────────────────────┐
│  (G)  USDG ↗                          [ Ink ]  ← 可选    │
│       [Ink]  Ink                                          │
├─────────────────────────────────────────────────────────┤
│  ┌─────────────────────────────────────────────────────┐ │
│  │            SUPPLY         |         BORROW           │ │
│  │          $23.61M ○                 $16.66M ○         │ │
│  │         (ds-text-12, 略加粗)                         │ │
│  └─────────────────────────────────────────────────────┘ │
├ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┤  ← border-t border-border/40
│  ┌─────────────────────────────────────────────────────┐ │
│  │  SUPPLY           SPREAD           BORROW            │ │  ← 三列都「标签居中+数值居中」
│  │  11.87%          +8.43%            3.44%             │ │    或统一 tabular-nums 对齐
│  │  2.16% + [9.71%]                                    │ │
```

### 3. 三列对齐方式对比

**当前：左 / 中 / 右**
```
SUPPLY              SPREAD              BORROW
11.87%              +8.43%              3.44%
2.16% + [9.71%]                          (空)
```

**建议：三列均居中**
```
      SUPPLY              SPREAD              BORROW
      11.87%              +8.43%              3.44%
  2.16% + [9.71%]
```

**或保持左右对齐但统一基线（tabular-nums）**
```
SUPPLY              SPREAD              BORROW
11.87%              +8.43%               3.44%
 2.16% + [9.71%]                            —
```
