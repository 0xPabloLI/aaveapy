# MobileReserveCard 排版示意（ASCII）

## 移动端排版核心原则

**移动端空间极其有限，必须最大化利用每一行水平空间：**

1. **优先横向一行排列** — 同一逻辑单元内的元素（标签 + 数值 + 图标）应尽量排在同一行，避免纵向堆叠浪费水平空间。例如 Spread toggle 的文字和展开图标应左右排列而非上下堆叠。
2. **避免居中堆叠** — 不要将小元素（图标、短文本）垂直居中独占一行；应让它们与同行其他内容共享水平空间。
3. **图标靠右** — 操作性图标（展开/折叠、菜单）放在行最右侧，信息性文字靠左，用 `justify-between` 撑满行宽。
4. **纵向堆叠仅用于逻辑分层** — 只有当上下两部分属于不同逻辑层级（如标签 vs 数值、控件 vs 面板）时才使用纵向布局，且每层仍应尽量横向填满。

> 违反此原则的典型反例：将 "Spread +8.43%" 和展开图标 ⌄ 上下堆叠，导致按钮高度翻倍但水平空间大量闲置。

### Spread 显示规则

- **Supply 标签页**：金额行左侧显示 Price（`$1.00`），与桌面端 Price 列一致
- **Borrow 标签页**：金额行左侧显示 Spread，格式为 `Sprd` 缩写 + 紫色百分比
  - 颜色：`ds-text-purple-600`（紫色），与桌面端 Spread 列、底部仿真切换条配色统一
  - 标签：`Sprd`（Bloomberg 金融行业标准缩写），`ds-text-10` 灰色，`ds-text-11` 紫色数值
  - 空值：显示 `-`，颜色退化为 `text-muted-foreground/60`
- **展开仿真面板**：Spread 值从 `displaySpread` 传入，与桌面端 `getDisplaySpread` 同源计算
- **Spread 排序默认标签**：按 Spread 排序时，移动端卡片自动切换到 Borrow 标签（`mobileCardDefaultTab`）

## Mobile Scenario Strip: Batch & Expand Icon 居中规则

在移动端 scenario strip 中，右侧列（Batch toggle + 展开 icon）必须与左侧 ScenarioControls 的上下两部分**各自居中**：

```
┌──────────────────────────────────────────────────────────┐
│  ┌── ScenarioControls (上) ──┐  ┌── 右侧列 (上) ──┐     │
│  │  USD│Token  Supply [____] │  │    Batch [3]     │     │  ← Batch 在上半区垂直居中
│  │          Borrow [____]    │  │      ⚪⚪        │     │
│  └───────────────────────────┘  └──────────────────┘     │
│  ┌── ScenarioControls (下) ──┐  ┌── 右侧列 (下) ──┐     │
│  │  ☑ Net lending & borrowing│  │       ⌄         │     │  ← 展开 icon 在下半区垂直居中
│  │  Net on: …               │  │                  │     │
│  └───────────────────────────┘  └──────────────────┘     │
└──────────────────────────────────────────────────────────┘
```

**实现要点：**
- 外层行使用 `flex items-stretch`（非 `items-start`），使右侧列拉伸到 ScenarioControls 全高
- 右侧列分为两个 `flex-1` 区块，各用 `flex items-center justify-center` 实现垂直居中
- 上半区：Batch toggle（`PortfolioModeToggle`）
- 下半区：展开 icon（`SlidersHorizontal` 按钮），仅在 `!isPortfolioMode` 时渲染
- 当 Net 面板收起（`mobileNetOpen === false`）时，下半区高度为 0，展开 icon 自然贴紧上半区底部

## Mobile Scenario Strip: 展开 Icon 位置稳定性规则

当 Net lending & borrowing 面板展开/收起时，Batch toggle 和展开 icon **位置不能移动**：

```
收起状态:                          展开状态:
┌──────────────────────┬────┐     ┌──────────────────────┬────┐
│ USD│Token Supply [__] │Batch│     │ USD│Token Supply [__] │Batch│  ← Batch 位置不变
│        Borrow [__]    │ ⌄  │     │        Borrow [__]    │ ⌄  │  ← ⌄ 位置不变
└──────────────────────┴────┘     └──────────────────────┴────┘
                                         ┌─────────────────┐
                                         │ ☑ Net lending & │  ← 绝对定位，不影响
                                         │   borrowing     │     ScenarioControls 高度
                                         └─────────────────┘
```

**实现要点：**
- Net 面板使用 `position: absolute`（`absolute left-0 right-0 top-full z-10`），脱离文档流
- ScenarioControls 父容器使用 `relative` 锚定绝对定位面板
- **禁止**将 Net 面板改回流式布局（如 `mt-1.5 px-0.5 pb-0.5`），否则 ScenarioControls 高度变化会导致右侧列 Batch/⌄ 位移
- 此规则与居中规则**同时满足**：绝对定位保证位置稳定，`items-stretch` + 双 `flex-1` 居中块保证各自居中

## Mobile SortBar 排版示意

移动端排序栏位于储备卡列表上方，由 5 个独立 chip 组成（桌面端列顺序一致）：

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│     [Size ⌄]  [Util ⌄]  [Supply ⌄]  [Borrow ⌄]  [Spread ⌄] │
│                                                              │
└──────────────────────────────────────────────────────────────┘
      ↑left-0    ↑left-0    ↑left-0      ↑right-0    ↑right-0
     (→向右展开) (→向右展开) (→向右展开)   (←向左展开)  (←向左展开)
```

### Chip 结构

每个 chip 为独立 `relative overflow-visible` 容器 + button + 绝对定位下拉菜单：

```
点击 Util chip 展开下拉:

  ┌──────────┐
  │  Util ⌄  │  ← button（chip 样式）
  └──────────┘
  ┌──────────────────┐
  │ ● Utilization ↓  │  ← absolute left-0 下拉菜单
  │   Liquidity  ↓   │
  └──────────────────┘

点击 Extra (Spread) chip 展开下拉:

                ┌──────────┐
                │ Spread ⌄ │  ← button
                └──────────┘
       ┌──────────────────┐
       │ ● Spread ↓       │  ← absolute right-0 下拉菜单
       │   Token ↑        │
       │   Market ↓       │
       │   Price ↓        │
       └──────────────────┘
```

### 边界约束规则

| 芯片 | 对齐 | 原因 |
|------|------|------|
| Size | `left-0` (→ 向右) | 行最左侧，右侧空间充裕 |
| Util | `left-0` (→ 向右) | 左侧区域，避免向左溢出视口 |
| Supply | `left-0` (→ 向右) | 左侧/中间区域 |
| Borrow | `right-0` (← 向左) | 右侧区域，避免向右溢出视口 |
| Extra | `right-0` (← 向左) | 行最右侧，左侧空间充裕 |

**额外防护**：所有菜单统一 `max-w-[min(18rem,calc(100vw-1.5rem))]` 视口感知宽度上限。
